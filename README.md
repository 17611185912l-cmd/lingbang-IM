# 领榜 IM 原型

公开预览：https://17611185912l-cmd.github.io/lingbang-IM/

此仓库保存静态构建产物，供 GitHub Pages 展示。当前版本包含首页、教师详情、消息页、四类通知二级页及用户/顾问双视角聊天演示。

聊天默认空白。从教师详情的联系顾问入口进入时，家长发送当前老师卡片，顾问发送欢迎语。双方共用会话并分别保留草稿；用户可发送图片、需求单、订单和老师，顾问可发送图片和老师，两侧提供独立常用语。老师选择支持科目、区域、老师类型及授课方式筛选。老师卡片进入对应教师详情；需求单和订单卡片仅提示“已跳转至详情”。

顾问侧展示演示用户陈女士：五年级、多项意向科目、西安新城区及最多三种授课方式。微信入口展示明确标注的演示二维码，长按可演示识别操作，不能添加真实好友。全部人物、资料、价格、通知与消息均为演示数据；聊天只保留在当前运行内存，刷新重置。图片仅在浏览器本地读取与预览，不上传服务器，不连接真实客服、机器人或业务接口。

当前页面规则展示在原型右侧，随消息与聊天场景切换。完整说明：[网页版](./prototype-guide.html) · [Markdown](./prototype-guide.md)。说明范围从教师详情的聊天入口开始，仅覆盖消息私信与聊天；不涵盖首页、通知归类/详情或教师详情其他功能。

已知限制：较矮桌面窗口打开顾问键盘时聊天区高度不足；顾问返回消息列表的入口名称仍显示芦顾问；阅读历史消息时打开工具会滚动到底部。当前发布保留这些已知问题。

GitHub Pages 使用 main 分支根目录，资源与说明文档适配 /lingbang-IM/ 子路径。发布校验见 release.json。
