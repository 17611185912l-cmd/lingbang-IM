# 领榜 IM 原型

公开预览：https://17611185912l-cmd.github.io/lingbang-IM/

此仓库保存静态构建产物，供 GitHub Pages 展示。包含首页、消息分类、四类通知二级页和用户/顾问双视角聊天演示。

通知分类：系统通知（维护、重大更新、平台公告）、服务通知（资料审核、用户邀请）、交易通知（支付、退款）、订单通知（需求进展、订单状态）。原需求通知已合并至订单通知。

聊天输入栏上方可切换用户与顾问视角，双方共用会话，草稿分别保留。用户可发送图片、需求单、订单、老师；顾问可发送图片、老师，两侧各有独立常用语。老师选择支持科目、区域、类型及授课方式筛选。三类发送卡片只提示“已跳转至详情”，不自建业务详情页。

顾问侧展示演示用户陈女士：五年级，多项意向科目，西安新城区及最多三种授课方式。全部人物、通知、聊天和偏好均为演示数据。预置15条消息，其中5条标注机器人来源；最后一条无机器人标注。聊天为浏览器本地模拟，刷新后重置，不接真实客服或机器人接口。图片在浏览器本地读取和预览，不上传服务器。

企业微信名片待配置；语音仅作布局展示。

GitHub Pages：main 分支，根目录。构建产物资源已适配 /lingbang-IM/ 子路径。更新时从本地 home-page 项目重新构建，仅更新本仓库发布产物。
