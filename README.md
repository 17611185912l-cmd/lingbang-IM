# 领榜 IM 原型

公开预览：https://17611185912l-cmd.github.io/lingbang-IM/

此仓库保存静态构建产物，供 GitHub Pages 展示。包含首页、消息分类、四类通知二级页及芦顾问聊天窗口。

全部人物、通知和聊天内容均为演示数据。聊天预置15条消息，其中5条标注机器人来源；最后一条无机器人标注。输入发送为浏览器本地模拟，刷新后重置，不接真实客服或机器人接口。

企业微信名片待配置；语音与附件图标仅作布局展示。

GitHub Pages：main 分支，根目录。构建产物资源已适配 /lingbang-IM/ 子路径。更新时从本地 home-page 项目重新构建，仅更新本仓库发布产物。
